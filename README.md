# AstroSentinel 
### AI-Based Fault Detection and Diagnosis for CubeSat Telemetry Systems

## Project Overview
AstroSentinel is a satellite health monitoring project designed to detect anomalies in CubeSat telemetry data and identify potentially affected satellite subsystems.

The project uses real satellite telemetry data from the ESA Anomaly Detection Benchmark.

## Objectives
- Detect abnormal patterns in satellite telemetry.
- Identify potential satellite subsystem faults.
- Support early fault detection and satellite health monitoring.
